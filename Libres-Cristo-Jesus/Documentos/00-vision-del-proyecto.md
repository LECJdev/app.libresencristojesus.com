VISIÓN DEL PROYECTO
Nombre del proyecto

LCJ Connect (Nombre temporal)

Nota: Podemos definir posteriormente el nombre comercial definitivo de la plataforma.

Propósito

Desarrollar una plataforma web moderna, intuitiva y escalable para administrar la estructura organizacional, el crecimiento, la asistencia y los indicadores de la iglesia Libres en Cristo Jesús.

La plataforma permitirá registrar, organizar y analizar toda la información relacionada con las Casas de Paz, facilitando el trabajo de líderes, pastores de distrito y pastores generales mediante herramientas digitales que simplifiquen la administración de la iglesia.

El sistema estará diseñado bajo una arquitectura moderna basada en Next.js y NestJS, priorizando la facilidad de uso desde dispositivos móviles mediante una Progressive Web App (PWA).

Objetivos

La plataforma debe permitir:

Digitalizar el control de asistencia de las Casas de Paz.
Mantener organizada la estructura jerárquica de la iglesia.
Facilitar la creación y administración de Distritos y Casas de Paz.
Registrar asistentes y mantener su historial.
Registrar las reuniones semanales.
Registrar el tema o prédica de cada reunión.
Registrar el valor de las ofrendas.
Registrar evidencia fotográfica de cada reunión.
Generar indicadores automáticos.
Mostrar dashboards interactivos.
Exportar información a Excel.
Funcionar correctamente desde computador y celular.
Poder instalarse como una aplicación (PWA).

Principios de Diseño

La aplicación NO debe sentirse como un software administrativo complejo.

Debe sentirse como una herramienta amigable.

Los principios visuales serán:

Diseño limpio.
Mucho espacio en blanco.
Iconografía clara.
Colores institucionales.
Navegación intuitiva.
Muy pocos clics para realizar una tarea.
Totalmente adaptable a dispositivos móviles.
Accesible para usuarios de cualquier edad.

Objetivo Final
